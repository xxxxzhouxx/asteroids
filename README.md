# Asteroids

A classic Asteroids arcade game built with Python and Pygame.

## Description

This project is a recreation of the classic Asteroids game, where you pilot
a ship through space, shooting and dodging asteroids as they drift and split
apart.

## Features

- Player-controlled ship with rotation and thrust
- Shooting mechanics
- Asteroids that split into smaller pieces when hit
- Collision detection

## Installation

Install pygame:
\`\`\`
pip install pygame
\`\`\`

## Usage

Run the game with:

\`\`\`
python main.py
\`\`\`

### Controls

- **W** - Thrust forward
- **A / D** - Rotate left/right
- **Space** - Shoot
